# City Map 3D

Выделяешь область на карте → утилита скачивает дороги и воду из OpenStreetMap,
строит рельефную модель (кварталы выше, дороги ниже, вода — углубление), режет её
на куски под стол принтера вдоль рек и крупных улиц, ставит замки «ласточкин хвост»
и сквозные отверстия под светодиоды. На выходе — `city_map.zip` с `piece_XX.stl`
и `layout.svg` (схема сборки 1:1 с номерами кусков).

## Запуск на Mac

1. Нужен Python 3.9+ (лучше 3.11+): `brew install python` или установщик с python.org.
2. Клонируй репозиторий и запусти:
   ```bash
   cd MapCutter
   ./start.command
   ```
   Или двойной клик по `start.command` в Finder (если macOS ругается —
   правый клик → «Открыть»). Первый запуск ставит зависимости в `.venv`, это пара минут.
3. Браузер откроется сам на http://localhost:8000.

На карте:
- **Карта** — двигать и зумить.
- **Область** — тянешь прямоугольник.
- **Светодиоды** — клик ставит точку, клик по точке убирает.
- **Собрать STL** — через 10–60 секунд скачается zip.

Без браузера:
```bash
.venv/bin/python cli.py --bbox 37.60 55.74 37.66 55.765 --width 500 --led 55.75 37.62 -o city.zip
```

## Параметры

Константы в начале `core.py`: высоты слоёв (`BASE_H`, `ROAD_H`, `BLOCK_H`),
ширины дорог по классам, размеры замков (`DT_*`), диаметр светодиода (`LED_D`).
Размер стола задаётся на странице (по умолчанию 256 мм). Каждый кусок в STL уже
развёрнут вдоль осей стола и лежит в начале координат.
